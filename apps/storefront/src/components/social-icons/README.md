فایل‌های SVG رسمی شبکه‌های اجتماعی ایرانی را در همین پوشه قرار بده.

قواعد:
- هر فایل فقط SVG همان شبکه باشد.
- بهتر است `fill="currentColor"` یا `stroke="currentColor"` استفاده شود.
- اگر SVG فعلی `fill="black"` دارد، فعلاً هم قابل‌استفاده است و بعداً در کد normalize می‌کنیم.
- نام فایل‌ها را دقیقاً مطابق این لیست نگه دار:
  - `bale.svg`
  - `rubika.svg`
  - `eitaa.svg`
  - `soroush.svg`

نحوه جایگذاری:
- محتوای کامل SVG هر شبکه را داخل فایل خودش paste کن.
- اگر از Figma خروجی می‌گیری، بهتر است export به‌صورت SVG باشد.

بعد از اینکه فایل‌ها را پر کردی، خبر بده تا آن‌ها را به فوتر وصل کنم.
